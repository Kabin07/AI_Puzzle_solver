Puzzle Solver

Set up a puzzle, pick an algorithm, then press Run to watch the search and the solution.

Shortcuts: Space pause / resume · ← → step
How to use the solver
1
Set up the puzzle
Type the initial and goal states in the grids (use _ or leave a cell empty for the blank), or click Generate Random Puzzle.
2
Choose an algorithm
GBFS (assigned) is selected. For GBFS / A* pick a heuristic; for DLS set the depth limit.
3
Run and explore
Press Run. Use Pause, Next / Prev to study each expansion, Skip to jump to the solution.
