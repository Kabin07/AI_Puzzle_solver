Algorithm Comparison

Every algorithm runs on the same puzzle instance. Times are measured without visualisation; very fast searches are repeated and averaged because browser timers are coarse.

How to compare
1
Pick the puzzle
The puzzle you used in the Solver is loaded automatically. Edit it or generate a new one.
2
Set the options
Choose the heuristic for GBFS / A* and the depth limits for DLS and IDDLS.
3
Run Comparison
Read the table, the four charts and the auto-generated observations. Download the table as CSV if needed.
