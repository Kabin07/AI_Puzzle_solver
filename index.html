Introduction to the 8-Puzzle Problem

The 8-puzzle is a 3×3 board holding eight numbered tiles and one blank square. A tile next to the blank can slide into it. Starting from an initial state, the task is to find a sequence of moves that reaches the goal state. Each board is a state, each slide is an action costing 1, and a solution is a path through the state space, which has 181,440 reachable states.

This project solves it with Greedy Best-First Search, an informed strategy. It uses a heuristic, Misplaced Tiles or Manhattan Distance, to always expand the state that looks closest to the goal.
